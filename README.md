# HR DataMart Learning Lab

Static GitHub Pages application with a guided scenario and a local CSV learning flow.

## Deploy
Upload the contents of this folder to the repository root, preserving `assets/` and `templates/`. Enable GitHub Pages from `main` and `/ (root)`.

## Scope
The guided flow demonstrates profiling, standardization, quality rules, quarantine, grain, history, star schema, KPI dependencies, impact simulation and a final Workforce Health dashboard. The public app should use synthetic or explicitly authorized data only.
